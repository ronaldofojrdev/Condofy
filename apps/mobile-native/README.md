# Condofy Mobile Native (scaffold)

Minimal Expo-based React Native scaffold with a native login screen.

Quick start:

```bash
cd apps/mobile-native
npm install
npx expo start
```

To run on a device or emulator:

```bash
npx expo run:android
npx expo run:ios
```

Notes:

- Replace `API_BASE` in `src/LoginScreen.js` with your backend URL.
- This scaffold is intentionally minimal: next steps are wiring navigation, secure token storage, and implementing the high-priority screens.
